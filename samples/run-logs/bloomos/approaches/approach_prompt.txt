3. How It Works: The Smart Hub Architecture
The core of the BloomOS ecosystem is the BloomHub 8, a wall-powered central station designed for efficiency and absolute reliability. It connects to up to eight separate plants via hybrid tethers, combining data collection and physical care delivery into a single loop.

It manages moisture decay curves, light schedules, and watering logic 100% locally. It uses Bluetooth for zero-friction setup and fallbacks, and WiFi for optional remote access. * The Pro Hub Option: Plasma-Activated Water (PAW): A breakthrough "fertilizer factory" option transforms the central reservoir into a decentralized nitrate source. * The Hybrid Umbilicals: A unified dual-channel cable assembly (clear silicone tube for water, 3-wire ribbon for power/data) eliminates messy, battery-dependent wireless sensors.
* The Intelligent Stakes: Each umbilical terminates in a durable, white ASA plastic stake. It combines multiple sensors—capacitive moisture, conductive pH/EC (only on the Pro model), and an ambient photodiode (for leaf-level light monitoring)—along with an integrated drip irrigation nozzle.

* BYO-AI & The Schema Moat: We empower users to connect their own AI endpoints (OpenAI, local Ollama, etc.). Our unique value is the proprietary, highly validated, domain-specific JSON schemas.
